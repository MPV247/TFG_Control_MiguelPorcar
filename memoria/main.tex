\chapter{Análisis}

En este capítulo se realiza un estudio detallado de los pilares que sustentan el desarrollo del sistema de control para el péndulo invertido. El análisis se articula en tres ejes fundamentales:

\begin{itemize}
	\item \textbf{Análisis de requisitos:} Donde se formalizan las capacidades operativas (funcionales) y las restricciones técnicas, de seguridad y rendimiento (no funcionales) que debe satisfacer el sistema.
	
	\item \textbf{Diseño del sistema:} Se describe la estrategia lógica y matemática adoptada, detallando el modelo dinámico, las leyes de control híbridas y la lógica de conmutación necesaria para el \textit{swing-up} y la estabilización.
	
	\item \textbf{Arquitectura del sistema:} Se define la infraestructura tanto de simulación como de implementación real, especificando el flujo de datos, la integración con ROS y la selección de los componentes de hardware que garantizan la viabilidad del proyecto.
	 
\end{itemize}

\section{Requisitos funcionales}
Los requisitos funcionales describen las acciones, cálculos y manipulaciones de datos específicos que el sistema debe realizar para cumplir su propósito. Para el control del péndulo invertido sobre carro se definen mediante sus entradas, comportamiento y salidas:

\begin{itemize}
	\item \textbf{RF1. Modelado y simulación de la dinámica:} 
	\begin{itemize}
		\item \textit{Entradas:} Parámetros físicos del sistema (masas, inercias, coeficientes de fricción) y señal de control simulada.
		\item \textit{Comportamiento:} Resolución matemática de las Ecuaciones Diferenciales Ordinarias (EDO) que rigen la dinámica no lineal del mecanismo en el entorno MATLAB/Simulink.
		\item \textit{Salidas:} Estado cinemático simulado del sistema (posiciones y velocidades articulares).
	\end{itemize}
	
	\item \textbf{RF2. Visualización y telemetría en ROS:}
	\begin{itemize}
		\item \textit{Entradas:} Estado cinemático del sistema (proveniente de la simulación o del hardware real) y archivo de descripción geométrica URDF.
		\item \textit{Comportamiento:} Traducción y publicación de los datos mediante el puente de comunicación de ROS Toolbox para actualizar el árbol de transformadas (TF) del robot.
		\item \textit{Salidas:} Visualización 3D actualizada en tiempo real mediante la interfaz RViz (tópico \textit{/joint\_states}).
	\end{itemize}
	
	\item \textbf{RF3. Control de inyección de energía (Swing-up):} 
	\begin{itemize}
		\item \textit{Entradas:} Posición y velocidad angular actual del péndulo ($q, \dot{q}$).
		\item \textit{Comportamiento:} Cálculo y ejecución de una ley de control basada en energía para balancear el péndulo desde su posición estable ($q = \pi \text{ rad}$) hasta el punto de linealización del sistema ($q = 0 \text{ rad}$).
		\item \textit{Salidas:} Acción de control ($u$).
	\end{itemize}
	
	\item \textbf{RF4. Control de estabilización (Realimentación del estado):} 
	\begin{itemize}
		\item \textit{Entradas:} Vector de estado del sistema ($x = [p, \dot{p}, q, \dot{q}]^T$). 
		\item \textit{Comportamiento:} Estabilización del sistema sobre el punto de linealización utilizando control por realimentación del estado. 
		\item \textit{Salidas:}  Acción de control ($u$).
	\end{itemize}
	
	\item \textbf{RF5. Adquisición y decodificación de señales:} 
	\begin{itemize}
		\item \textit{Entradas:} Señales eléctricas de pulsos en cuadratura (A y B) provenientes de los encoders del motor y del péndulo.
		\item \textit{Comportamiento:} Procesamiento y conteo de los pulsos digitales mediante el hardware específico.
		\item \textit{Salidas:} Valores digitales discretos de posición y velocidad interpretables por la ley de control.
	\end{itemize}
\end{itemize}

\section{Requisitos no funcionales}
Los requisitos no funcionales imponen condiciones y restricciones a la implementación del diseño:

\begin{itemize}
	\item \textbf{RNF1. Restricciones de rendimiento (Determinismo y tiempo real):} El bucle de control debe ejecutarse dentro de una rutina de interrupción periódica en un microcontrolador, garantizando un periodo de muestreo estable y un \textit{jitter} despreciable para la viabilidad del control discreto.
	
	\item \textbf{RNF2. Restricciones de fiabilidad (Robustez):} El sistema debe rechazar perturbaciones externas moderadas y ser tolerante a las discrepancias producidas por dinámicas no modeladas (fricciones no lineales y holguras mecánicas).
	
	\item \textbf{RNF3. Restricciones de seguridad (Gestión de fallos):} 
	\begin{itemize}
		\item \textit{Seguridad mecánica:} El software debe implementar una parada de emergencia si las lecturas de posición indican que el carro excede los límites físicos del riel. En caso de fallo en el software de parada se debe disponer de finales de carrera para cortar la alimentación del actuador. 
		\item \textit{Seguridad eléctrica:} Se debe garantizar el aislamiento galvánico entre la etapa de control (3.3V) y la etapa de potencia (24V).
	\end{itemize}
	
	\item \textbf{RNF4. Condiciones de implementación (Abstracción HAL):} El código desarrollado debe hacer uso de la capa de abstracción de hardware (HAL) ofrecida por el fabricante del microcontrolador, asegurando la portabilidad, estandarización y eficiencia del firmware.
\end{itemize}

\subsection{Introducción al modelado dinámico}

A diferencia de la cinemática, que estudia el movimiento de un mecanismo sin considerar las fuerzas y pares que lo producen, el modelado dinámico describe explícitamente la relación entre la fuerza aplicada y el movimiento resultante \cite{spong2006robot}. Disponer de las ecuaciones de movimiento exactas es un requisito estricto y fundamental tanto para la simulación del sistema como para el diseño de controladores basados en modelo. 

Para determinar la dinámica del péndulo invertido sobre carro, se recurre a las ecuaciones de Euler-Lagrange. Este enfoque energético se basa en la obtención del Lagrangiano del sistema ($L$), definido como la diferencia entre la energía cinética ($E_c$) y la energía potencial ($E_p$):

\begin{equation}
	\begin{cases} 
		L = E_c - E_p
	\end{cases}
	\label{eq:lagrangiano}
\end{equation}

Las ecuaciones diferenciales no lineales resultantes pueden reescribirse y compactarse de forma elegante en la formulación matricial clásica para sistemas robóticos \cite{murray1994mathematical}:

\begin{equation}
	\begin{cases} 
		M(q)\ddot{q} + C(q,\dot{q})\dot{q} + G(q) = B u
	\end{cases}
	\label{eq:matrices_dinamica}
\end{equation}

Para el sistema en concreto, las dimensiones de cada matriz son:
\begin{itemize}
	\item $M(q) \in \mathbb{R}^{2 \times 2}$ es la matriz de inercia.
	\item $C(q,\dot{q}) \in \mathbb{R}^{2 \times 2}$ es la matriz de fuerzas centrípetas y de Coriolis.
	\item $G(q) \in \mathbb{R}^{2 \times 1}$ es el vector de fuerzas gravitacionales.
	\item $B \in \mathbb{R}^{2 \times 1}$ vector de entrada, mapea la acción de control $u$.
\end{itemize}

Este enfoque matricial no solo facilita el análisis teórico, sino que permite realizar correcciones en la simulación del sistema muy fácilmente, ya que los parámetros que lo caracterizan (masas, longitudes, inercias, etc.) se encapsulan dentro de las propias matrices.  

\subsection{Modelo dinámico del sistema}
El primer paso para el modelado dinámico consiste en definir un sistema de referencia en el plano bidimensional $(x, y)$. Esto permite localizar la posición del centro de masas (CM) del péndulo en función de las coordenadas generalizadas del sistema: la posición lineal del carro ($x$) y la posición angular del péndulo ($\theta$).

Considerando $l$ como la distancia desde el eje de rotación hasta el centro de masas del péndulo, sus coordenadas son:

\begin{equation}
	\begin{cases}
		x_{\text{cm}} = x + l \sin(\theta) \\
		y_{\text{cm}} = l \cos(\theta)
	\end{cases}\label{eq:coordenadas_cm}
\end{equation}

Esta elección de coordenadas establece de forma implícita el marco de trabajo del controlador. Se define la vertical superior como el origen angular ($\theta = 0$ rad) y de acuerdo con la geometría de la Ecuación \ref{eq:coordenadas_cm}, se asume una convención de signos donde el sentido de giro horario se considera positivo para el incremento de $\theta$.


 \begin{figure}[htpb]
 	\centering
	\input{Pictures/figuras/pendulo_carro_cm.tex}
 	\caption{Esquema cinemático, definición del sistema de coordenadas}
 	\label{fig:esquema_pendulo}
 \end{figure}

\FloatBarrier

Una vez establecida la convención de signos del sistema y tener una visión esquemática ofrecida en la Figura \ref{fig:esquema_pendulo}, es momento de desarrollar la Ecuación \ref{eq:lagrangiano} hasta obtener la forma matricial compacta de la Ecuación \ref{eq:matrices_dinamica}. La energía potencial y cinética del sistema en concreto se puede representar como \cite{tedrake2023}:

\begin{equation}
	\begin{cases}
		E_{\text{c}} = \frac{1}{2}(M + m)\dot{x}^2 + m\dot{x}\dot{\theta} l\cos(\theta) + \frac{1}{2}  ml^2\dot{\theta}^2 \\
		E_{\text{p}} = mgl\cos(\theta)
	\end{cases}\label{eq:energia_sistema}
\end{equation}

A partir de formular la energía cinética y potencial, se desarrolla el Lagrangiano (Anexo \ref{anexo:desarrollo_dinamico}) y se calculan sus derivadas parciales hasta obtener las siguientes ecuaciones de movimiento \cite{tedrake2023}:

\begin{equation}
	\begin{cases}
		(M + m)\ddot{x} + ml\ddot{\theta}\cos(\theta) - ml\dot{\theta}^2\sin(\theta) = u \\
		ml\ddot{x}\cos(\theta) + ml^2\ddot{\theta} - mgl\sin(\theta) = 0
	\end{cases}\label{eq:ec_movimiento}
\end{equation}

Antes de compactar las ecuaciones en la forma matricial de la Ecuación \ref{eq:matrices_dinamica} es importante añadir los términos de rozamiento viscoso para el riel y el péndulo.  

\begin{equation}
	\begin{cases}
		(M + m)\ddot{x} + ml\ddot{\theta}\cos(\theta) + c_x\dot{x} - ml\dot{\theta}^2\sin(\theta) = u \\
		ml\ddot{x}\cos(\theta) + ml^2\ddot{\theta} + c_{\theta}\dot{\theta} - mgl\sin(\theta) = 0
	\end{cases}\label{eq:ec_movimiento_final}
\end{equation}

Finalmente se compacta la expresión en forma matricial como indica la Ecuación \ref{eq:matrices_dinamica}. La caracterización del sistema que posteriormente se implementará en simulación es: 

\begin{equation}
	\begin{bmatrix} 
		M + m & m l \cos\theta \\ 
		m l \cos\theta & I + m l^2 
	\end{bmatrix} 
	\begin{bmatrix} 
		\ddot{x} \\ 
		\ddot{\theta} 
	\end{bmatrix} 
	+ 
	\begin{bmatrix} 
		c_x & -m l \dot{\theta} \sin\theta \\ 
		0 & c_\theta 
	\end{bmatrix} 
	\begin{bmatrix} 
		\dot{x} \\ 
		\dot{\theta} 
	\end{bmatrix} 
	+ 
	\begin{bmatrix} 
		0 \\ 
		-m g l \sin\theta 
	\end{bmatrix} 
	= 
	\begin{bmatrix} 
		1 \\ 
		0 
	\end{bmatrix} u
	\label{eq:matrices_dinamica_desarrollada}
\end{equation}

Si se analiza la Ecuación \ref{eq:matrices_dinamica_desarrollada} se deducen tres características clave del sistema: 
\begin{itemize}[]
	\item \textbf{Sistema subactuado:} La acción de control $u$ solo permite empujar el carro de forma horizontal, no hay control directo en el posicionado del péndulo. 
	
	\item \textbf{Acoplamiento de términos:} El movimiento del carro afecta a la posición del péndulo y a su vez el movimiento del péndulo actúa como una perturbación en el posicionado del carro. 
	
	\item \textbf{Sistema inestable:} Si se analiza el sistema en $\theta = 0\ rad$ presenta polos con parte real positiva debido al término $	-m g l \sin\theta $. Por tanto, se requiere aplicar acciones de control en bucle cerrado para poder permanecer en esta posición. 
	
\end{itemize}

\subsection{Estrategia de control Swing-up}

La primera ley de control se centra en el levantamiento del péndulo desde su posición estable ($\theta = \pi\ rad$) hasta su posición inestable y punto en el que se conmuta al control de posición ($\theta = 0\ rad$). 

La idea intuitiva tras las matemáticas es simple, consiste en balancear el péndulo inyectando energía a favor del movimiento. El objetivo es llegar al punto de estabilización con pequeñas acciones de control que producen oscilaciones de amplitud creciente en el sistema. 
\begin{figure}[ht]
	\centering
	\input{Pictures/figuras/swing_up_simple.tex}
	\caption{Esquema del control por balanceo (swing-up) basado en energía.}
	\label{fig:swing_up_simple}
\end{figure}

Para formalizar la ley de control esquematizada en la Figura \ref{fig:swing_up_simple}, se define la energía del péndulo libre que viene dada por la suma de la energía potencial y la cinética \cite{astrom2000swinging}: 
\begin{equation}
	\begin{cases} 
		E_m = E_c + E_p = \frac{1}{2}J\dot{\theta}^2 + mgl\cos(\theta) 
	\end{cases}
	\label{eq:pendulo_simple}
\end{equation}

En el caso de la Ecuación \ref{eq:pendulo_simple} se define la máxima energía potencial cuando $\theta = 0\ rad$ de forma que el sistema de referencia del control coincide con el del modelado. Una vez se formaliza el modelo energético, se determina la referencia energética que el control por balanceo debe conseguir \cite{astrom2000swinging}:
\begin{equation}
	\begin{cases} 
		E_{ref} = mgl
	\end{cases}
	\label{eq:energia_ref}
\end{equation}

Por otro lado, el error de medida para calcular la acción de control $u$ viene dado por la diferencia entre la energía actual del péndulo ($E_m$, Ecuación \ref{eq:pendulo_simple}) y la energía de referencia ($E_{ref}$, Ecuación \ref{eq:energia_ref}) \cite{astrom2000swinging}:
\begin{equation}
	\begin{cases} 
		e = E_{m} - E_{ref}
	\end{cases}
	\label{eq:error_energia}
\end{equation}

Finalmente se define la ley de control que permite balancear el péndulo simple hasta su posición inestable, donde la acción de control $u$ es el par aplicado en el eje de rotación \cite{astrom2000swinging}: 
\begin{equation}
	\begin{cases} 
		u = K\dot{\theta}\cos(\theta)e
	\end{cases}
	\label{eq:ley_control_swp}
\end{equation}

En función del valor de la ganancia $K$ se conseguirá el objetivo en diferente número de oscilaciones. Valores pequeños de la ganancia requieren de más iteraciones para llegar hasta el punto de estabilización. 

Sin embargo, la ley de control definida en la Ecuación \ref{eq:ley_control_swp} no es directamente transferible al péndulo invertido sobre carro. Los motivos son los siguientes:

\begin{itemize}[topsep=5pt, itemsep=4pt] % Ajuste fino de espacios
	\item \textbf{Acción de control:} En la ley de control propuesta en \ref{eq:ley_control_swp} el actuador se encuentra en el eje del péndulo. El sistema definido en \ref{eq:matrices_dinamica_desarrollada} es subactuado y solo se tiene control sobre la fuerza de empuje del carro. Para aplicar la estrategia de energía, es necesario convertir la acción de control virtual (el par necesario en el eje) a una aceleración real del carro a través del acoplamiento dinámico del sistema.
	
	\item \textbf{Límites físicos del riel:} Se hace indispensable, por tanto, un control multiobjetivo que regule la energía del péndulo garantizando simultáneamente la estabilidad de la posición del carro dentro del espacio de trabajo del riel.
\end{itemize}

Para abordar las limitaciones mencionadas, se recurre a la técnica de \textbf{Linearización por Realimentación Parcial (PFL)}. Esta metodología es fundamental en el estudio de sistemas mecánicos subactuados, definidos como aquellos que poseen menos actuadores que grados de libertad \cite{spong1994}. La PFL permite transformar la dinámica de un subconjunto de las coordenadas del sistema en un sistema lineal mediante un cambio de variables y una ley de control no lineal, siempre que exista un acoplamiento inercial suficiente entre las coordenadas actuadas y las pasivas \cite{spong1994}.

En este trabajo se aplica la variante conocida como \textbf{linealización colocalizada} (\textit{Collocated Linearization}), la cual consiste en linealizar el grado de libertad activo del sistema, es decir, aquel donde se ubica físicamente la acción de control. El objetivo es diseñar una ley de control $u$ que cancele las no linealidades de la dinámica del carro para que este se comporte, desde el punto de vista del controlador de alto nivel, como un doble integrador lineal respecto a una aceleración deseada $\ddot{x}_{des}$.

Partiendo de la ecuación de movimiento para la coordenada actuada del carro:
\begin{equation}
	(M + m)\ddot{x} + c_x\dot{x} +ml\cos\theta\ddot{\theta} - ml\dot{\theta}^2\sin\theta = u
	\label{eq:dinamica_carro_base}
\end{equation}

Se busca imponer la condición $\ddot{x} = \ddot{x}_{des}$. Despejando la fuerza $u$ necesaria en la ecuación \ref{eq:dinamica_carro_base}, se obtiene la ley de control por linealización parcial:
\begin{equation}
	u = (M + m)\ddot{x}_{des} + ml\cos\theta\ddot{\theta} - ml\dot{\theta}^2\sin\theta
	\label{eq:PFL_u_final}
\end{equation}

Como se observa, la fuerza física aplicada por el motor ($u$) compensa dinámicamente la masa total y los efectos inerciales del péndulo. Esta arquitectura permite definir la aceleración deseada $\ddot{x}_{des}$ como el punto de encuentro donde convergen los dos objetivos de control del sistema \cite{tedrake2023}:

\begin{equation}
	\ddot{x}_{des} = \underbrace{K_e \dot{\theta} \cos\theta (E - E_{ref})}_{\text{Control de Energía (Swing-up)}} - \underbrace{(K_p x + K_d \dot{x})}_{\text{Control de Posición (PD)}}
	\label{eq:aceleracion_deseada}
\end{equation}

\newpage

La ley de control resultante en la ecuación \ref{eq:aceleracion_deseada} simboliza un compromiso entre la inyección de energía necesaria para el balanceo y la regulación de la posición del carro sobre el riel \cite{tedrake2023}. Se debe ajustar el peso de cada ganancia para obtener un equilibrio óptimo entre ambos controles.

Finalmente, la figura \ref{fig:PFL} muestra de forma conceptual la arquitectura de control para la combinación de ambas técnicas. Se observa como el bloque PFL actúa como un control interno que hace creer a los controladores externos que la planta a controlar es un doble integrador, permitiendo tener acciones de control virtuales de aceleración. 


Para que la estrategia de control sea implementable, es necesario que la ley de control final no dependa de variables que no podamos medir o dictar directamente. En el caso de la PFL colocalizada, el objetivo es que el carro siga una aceleración deseada $\ddot{x}_{des}$, pero la fuerza física $u$ en la ecuación \ref{eq:dinamica_carro_base} depende de la aceleración angular $\ddot{\theta}$, la cual es una variable pasiva.

Partimos de las ecuaciones de movimiento del sistema que incluyen los términos de fricción del carro ($c_x$) y del péndulo ($c_{\theta}$):
\begin{equation}
	\begin{cases}
		(M + m)\ddot{x} + ml\ddot{\theta}\cos(\theta) + c_x\dot{x} - ml\dot{\theta}^2\sin(\theta) = u \\
		ml\ddot{x}\cos(\theta) + J\ddot{\theta} + c_{\theta}\dot{\theta} - mgl\sin(\theta) = 0
	\end{cases}\label{eq:ec_mov}
\end{equation}

Donde $J = I + ml^2$ es el momento de inercia del péndulo respecto al eje de rotación. Para eliminar $\ddot{\theta}$ de la ecuación de control, despejamos dicha variable de la dinámica del péndulo:
\begin{equation}
	\begin{cases}
	\ddot{\theta} = \frac{1}{J} \left( mgl\sin\theta - ml\cos\theta\ddot{x} - c_p\dot{\theta} \right)
	\end{cases}
	\label{eq:despeje_theta}
\end{equation}

Al imponer la condición de linealización $\ddot{x} = \ddot{x}_{des}$ y sustituir la expresión \ref{eq:despeje_theta} en la ecuación del carro, se obtiene la fuerza $u$ necesaria para anular la dinámica no lineal del subsistema actuado:
\begin{equation}
	u = (M + m)\ddot{x}_{des} + ml\cos\theta \left[ \frac{1}{J} (mgl\sin\theta - ml\cos\theta\ddot{x}_{des} - c_p\dot{\theta}) \right] - ml\dot{\theta}^2\sin\theta + c_x\dot{x}
\end{equation}

Agrupando los términos en función de la entrada virtual $\ddot{x}_{des}$, se obtiene la ley de control por linealización parcial colocalizada desplegada:
\begin{equation}
	u = \underbrace{\left[ (M + m) - \frac{(ml\cos\theta)^2}{J} \right]}_{\text{Inercia efectiva}} \ddot{x}_{des} + \underbrace{\frac{m^2l^2g\cos\theta\sin\theta}{J} - \frac{mlc_p\cos\theta\dot{\theta}}{J} - ml\dot{\theta}^2\sin\theta + c_x\dot{x}}_{\text{Términos de acoplamiento y fricción}}
	\label{eq:u_pfl_completa}
\end{equation}

La ecuación \ref{eq:u_pfl_completa} representa la implementación real del bloque PFL. El primer término entre corchetes define la \textit{inercia efectiva} del sistema visto desde el actuador; nótese cómo esta inercia varía en función del ángulo del péndulo debido al acoplamiento. El segundo bloque de términos compensa las fuerzas gravitatorias, centrífugas y de fricción. 

Gracias a esta formulación, el diseño de los controladores de swing-up y posición se simplifica drásticamente, ya que pueden considerar al carro como una masa unitaria ideal que responde de forma lineal a la aceleración $\ddot{x}_{des}$, delegando toda la compensación de la dinámica no lineal al nivel de control inferior definido por la PFL.

\subsection{Lógica de conmutación}

Finalmente, la lógica de conmutación atiende a un umbral angular. Este bloque de decisión monitoriza de forma continua la posición angular estimada del péndulo ($\hat{\theta}$). Si el péndulo ingresa dentro de una vecindad acotada en torno a la vertical absoluta (\textit{el punto de linealización del sistema}), la lógica conmuta al control por realimentación del estado En caso contrario, el sistema mantiene activo el controlador de swing-up para elevar el mecanismo. Este comportamiento híbrido se formaliza en el siguiente pseudocódigo:

\begin{algorithm}[H]
	\caption{Lógica de Conmutación}
	\label{alg:conmutacion}
	\begin{algorithmic}[1]
		\Require Vector de estados estimado $\hat{x} = [\hat{x}_c, \dot{\hat{x}}_c, \hat{\theta}, \dot{\hat{\theta}}]^T$, umbral angular $\theta_{\text{th}}$
		\Ensure Señal de control $u$ a aplicar a la planta
		\Statex
		\Loop
		\State $\hat{\theta} \gets \hat{x}(3)$ \Comment{Obtener posición angular actual}
		\If{$|\hat{\theta}| \leq \theta_{\text{th}}$} 
		\State $u \gets -K \hat{x}$ \Comment{Control de posición}
		\Else 
		\State $u \gets f_{\text{swing}}(\hat{x})$ \Comment{Control de energía}
		\EndIf
		\State 
		\EndLoop
	\end{algorithmic}
\end{algorithm}

Esta estructura permite observar la interacción entre el entorno digital (discreto) y el proceso físico (continuo). El núcleo del sistema es el \textbf{Controlador Digital}. Este procesador se encarga de ejecutar el algoritmo de control que procesa la señal de error entre la referencia ($r_k$) y la realimentación ($y_k$). 

El concepto fundamental es el \textbf{periodo de muestreo} ($T$). Este parámetro determina la periodicidad de la rutina de control, permitiendo sincronizar las etapas de medida, cálculo y actuación sobre la planta de manera precisa. Durante el desarrollo del proyecto se determinará el periodo de muestreo atendiendo a factores como la dinámica del sistema en bucle cerrado o la frecuencia de la señal PWM. 

Finalmente la interacción entre el mundo digital y el mundo físico es posible mediante el uso de \textbf{periféricos} que permiten medir el estado del sistema o modificarlo. Diferenciamos en dos clases de periféricos: 
\begin{itemize}[]
	\item \textbf{Actuadores:} La señal de control digital ($u_k$) se convierte en una señal analógica o cuasi-analógica mediante el módulo \textit{ePWM} (DAC, convertidor digital-analógico). Posteriormente, un bloque \textit{Retenedor de orden cero} (ZOH) mantiene la señal constante durante el intervalo de muestreo, transformándola en la señal continua $u(t)$ que excita al Proceso Continuo (compuesto por el driver, el motor y el péndulo).
	
	\item \textbf{Sensores: } La respuesta del sistema ($y_p(t)$) es captada por los sensores (en este caso, encoders). La señal $y(t)$ es procesada por un bloque de muestreo, gobernado por el periodo $T$, y enviada al periférico\textit{ eQEP}.Este último actúa como un equivalente a un ADC (convertidor analógico-digital), transformando los pulsos del encoder en una señal digital $y_k$ interpretable por el controlador.
\end{itemize}
